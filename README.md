# Proyek-Akhir-Membangun-Aplikasi-Catatan-Menggunakan-React
Proyek akhir berupa aplikasi catatan (Notes App) yang dibangun menggunakan React. Aplikasi ini memiliki fitur untuk membuat, menampilkan, mencari, menghapus, mengarsipkan, dan memindahkan kembali catatan. Proyek ini dibuat untuk menerapkan konsep React seperti component, props, state, event handling, controlled component.
